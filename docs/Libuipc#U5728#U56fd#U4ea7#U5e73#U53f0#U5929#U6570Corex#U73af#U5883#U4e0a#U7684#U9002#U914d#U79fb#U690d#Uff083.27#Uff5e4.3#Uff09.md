# Libuipc在国产平台天数Corex环境上的适配移植

### 1.1 Libuipc中用到的CUDA API测试

对 libuipc 生产代码（`src/backends/cuda` + `external/muda/src`）中实际调用的 CUDA API 进行了系统性的测试，覆盖 cuBLAS、cuSPARSE、cuSOLVER、CUDA Graph 、Runtime五大模块，共编写 5 个独立测试程序。

以下是测试中发现的**异常 API**：

**A 类 — CUDART 10.x 下无法编译：**

| 条件 | API |
|------|-----|
| `>= 11020` | `cudaMallocAsync`、`cudaFreeAsync` |
| `>= 11010` | `cudaGraphUpload` |
| `>= 11000` | `cublasNrm2Ex`、`cusolverDnX*`、`cudaEventRecordWithFlags`、`cudaGraphExecMemcpyNodeSetParams1D` 等 |

**B 类 — 运行时 NOT_SUPPORTED：**

| 库 | API | 说明 |
|----|-----|------|
| cuBLAS | `cublasDdot`、`cublasDnrm2` | 双精度点积和范数不支持 |
| cuSOLVER | `cusolverDnDpotrf`/`Dpotrs` | Cholesky 分解/求解不支持 |
| cuSOLVER | `cusolverDnDgetrs` | LU 求解不支持（Dgetrf 分解本身正常） |
| cuSOLVER | `cusolverSpCreate` | 稀疏句柄创建失败，导致 `SpDcsrlsvqr`/`SpScsrlsvqr` 等稀疏 QR 全部无法使用 |

**C 类 — 兼容异常：**

| 库 | API | 说明 |
|----|-----|------|
| cuSPARSE | `cusparseSpMV` | 调用成功但结果全零 |





### 1.2 `ParallelFor` 设备端 lambda 捕获机制修复

**问题**：CoreX 环境下 `muda::ParallelFor` 的设备端 lambda 捕获静默失败 — 编译通过、无运行时报错，但 kernel 不执行任何计算。这导致仿真输出完全静止。

**可能的原因**：CoreX 的 clang-CUDA 编译器和运行时在处理以匿名 lambda 类型为模板参数的 kernel 实例化时，host 端的符号与 device 端 fatbin 中的符号无法正确匹配，kernel 在运行时找不到对应的 GPU 代码。

**影响范围**：PCG 线性求解器、全局线性系统组装、仿射体动力学（能量/梯度/Hessian）、对角预条件器、线搜索等。

**当前修复策略**：

1. 重写为 `__global__` kernel + 裸指针参数
3. 主机端回退

修复涉及 `linear_pcg.cu`、`global_linear_system.cu`、`abd_diag_preconditioner.cu`、`affine_body_dynamics.cu`、`ortho_potential.cu` 等 9 个文件。

修复后验证：simple 场景（两四面体，contact 关闭）200 帧自由落体正常，Newton 199/199 帧收敛，Y 方向轨迹与理论值误差 < 0.6%。




### 1.3 CoreX GPU 双精度减法 Bug

**现象**：修复 `ParallelFor` 后，四面体在 X/Z 方向出现约 2.0 单位的瞬移。追踪发现动能梯度 GPU 计算结果与主机端不一致：

```
gpu_grad  = [-1082.5, 0.424, -1082.5, ...]  ← 异常
host_grad = [0.0,     0.424, 0.0,     ...]  ← 正确
```

**根因**：编写诊断 kernel 发现 CoreX GPU 存在 双精度减法 bug：

```cpp
out[0] = q_raw[0];              // → 0.0  ✓
out[1] = qt_raw[0];             // → 0.0  ✓
out[2] = q_raw[0] - qt_raw[0];  // → -2.0 ✗ （应为 0.0）
```

单独读取正确， 减法异常。`volatile`、标量减法均无法绕过。
